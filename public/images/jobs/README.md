# Character header job sprites

The Corsair (캡틴) sprite comes from [NEXON's official MapleStory Japan job introduction](https://maplestory.nexon.co.jp/job/adventurer/captain/).

- Original source: [char_02.webp](https://static.nexon.co.jp/maplestory/ver2017/job/adventurer/captain/char_02.webp)
- Local file: `corsair.webp` (72×86, 4,732 bytes, static WebP with transparency)
- Artwork: © NEXON
- Provenance and SHA-256: `sources.json`

The original file is unchanged. CSS preserves its aspect ratio and uses pixelated rendering. The app serves it locally only when Corsair is selected; other jobs retain their existing icon. This is a representative job illustration, not an image of the user's actual character. No gameplay statistics or rules are taken from the reference page.
