# Corsair equipment icon sources

Original MapleStory game artwork © NEXON. Retrieved through [MapleStory.io](https://maplestory.io/) using its documented item icon endpoint, pinned to **GMS 83**.

`sources.json` records each item ID, provider name, source URL, retrieval time, dimensions, byte length, and SHA-256. PNG files are the original downloaded responses without cropping, recoloring, or AI generation.

These are representative slot illustrations, not identification of a user's equipped items. Canopus armor and Dragonfire Revolver represent the Pirate/Corsair slots; accessories represent shared equipment. Both pendant slots use the same generic pendant artwork. Unknown custom slots, buffs/blessings, and other jobs keep their existing SVG illustrations.

Only artwork is used. The provider's levels, stats, and equipment rules are **not** applied to MaplePlanet calculations. Images are served locally with the app; browsers make no runtime request to the image provider. No user screenshot is included.
