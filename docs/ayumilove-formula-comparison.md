# Ayumilove 공식과 현재 플래닛 계산 비교

확인일: 2026-09-28 KST. 코드 기준: `df22238546789bff37979e495a3c366a09bd6b8e`.

사용자가 제공한 [MapleStory Formula Compilation](https://ayumilovemaple.wordpress.com/2009/09/06/maplestory-formula-compilation/)은 2009-09-06에 작성된 구버전 메이플 공식 정리다. 문서 자체에 플래닛 전용 규칙이나 2026년 패치 적용 설명은 없다. 이번 작업은 해당 문서·플래닛 공식 공지·현재 코드의 비교이며, 계산식 변경 결정이나 게임 전체의 실측 검증이 아니다. D-027의 현재 계산 방식 유지 정책을 따른다.

## 비교 결과

아래 스탯은 장비·버프 처리 후 최종값이며 `A`는 최종 공격력이다. `floor`는 소수점 아래 버림을 뜻한다.

| 항목 | 제공 문서 | 현재 코드 | 판단 |
| --- | --- | --- | --- |
| 캡틴·신궁 최대 스탯공 | `(DEX × 3.6 + STR) × A / 100` | 같은 식의 결과를 버림 | 기본식 일치 |
| 나이트로드 일반 최대 스탯공 | `(LUK × 3.6 + DEX + STR) × A / 100` | 같은 식의 결과를 버림 | 일반 스탯공 기본식 일치 |
| 럭키세븐·트리플스로우 | 스킬 전용 기본 최대 `LUK × 5 × A / 100`, 최소 `LUK × 2.5 × A / 100` | 스킬별 기본 피해 분기 없이 일반 최대 스탯공으로 환산공 계산 | 나이트로드 스킬 피해 비교에 차이 가능 |
| 최소값·숙련도 | 별도 최소값 공식 | 최대 스탯공만 제공 | 현재 최대값 중심 범위와 구분 |
| 방어 처리 | 고정 방어력·레벨 차에 따른 차감 | 대상 방어율에서 방무 합계를 차감 | 플래닛의 방어율 규칙은 별도 공식 공지로 확인 |
| 크리티컬 처리 | 스킬 배율에 추가 크리 배율을 더함 | 그 구조에서 유도한 크리 기대 배율 사용 | 플래닛 공식과 구조 일치 |
| 실제 타격 피해 | 피해 범위 추첨·스킬 배율·타격별 보정·상한 등 포함 | 최대 스탯공 기반 비교 지표 | 환산공과 실제 피해량을 직접 비교할 수 없음 |

제공 문서의 전용 스킬 공식은 **능력창 최대 스탯공을 5.0 계수로 바꾸라는 뜻이 아니다.** 나이트로드의 실제 스킬 성능을 다룰 때 스탯공과 별도 기본 피해 모델이 필요할 수 있다는 근거다. 플래닛에서 해당 전용식을 유지하는지는 공식 근거 또는 실제 측정으로 추가 확인해야 한다. 현재 나이트로드 구매 후보 비교는 세 번째 스탯 STR 교체 모델 등의 제약으로 지원하지 않는다.

## 현재 계산과 공식 근거

현재 공격력은 다음과 같다. 공격력%는 장비 공격력에만 적용하고 탄약·축복·길드·달성·일반 버프 공격력은 별도로 더한다. 제공 문서는 플래닛의 잠재능력·달성 버프 적용 순서를 검증할 자료가 아니므로 D-030의 사용자 확인 정책을 유지한다.

```text
A = floor(장비 공격력 × (1 + 공격력% / 100)) + 비장비 공격력
최종 스탯 = floor((순수 + 장비 + 달성 올스탯) × (1 + 스탯% / 100))
            + floor(순수 × 메이플 용사 비율)
```

현재 환산공은 최대 스탯공을 기준으로 다음 배율을 반영한다. 보스전은 총데미지와 보공을 합산하고 사냥에서는 보공을 제외한다.

```text
환산공 = floor(최대 스탯공 × 데미지 배율 × 방어율 배율 × 크리 배율)
방어율 배율 = max(0, 1 - max(0, 대상 방어율 - 합산 방무) / 100)
크리 배율 = 1 + (크리 확률% / 100) × (추가 크리 데미지%p / 스킬 데미지%)
```

[2026-06-23 공식 공지](https://mapleplanet.co.kr/news/updates/623)는 플래닛의 최종 방어율을 대상 방어율에서 방무 옵션 합계를 뺀 값으로 안내한다. 방어율 80%·방무 60%라면 남는 방어율 20%, 현재 배율은 0.8이다. 이 공지는 제공 문서의 고정 방어력이나 레벨 차감 항이 플래닛에서 모두 없어졌다는 근거까지 제공하지 않는다. 현재 앱에는 그 항들의 입력·계산이 없다.

[2026-03-24 공식 공지](https://mapleplanet.co.kr/news/updates/465)는 크리티컬 피해를 `기본 피해 × (스킬% + 크리%)`로 변경하고, 샤프아이즈 30의 추가 크리데미지를 140%, 쓸만한 샤프아이즈는 115%로 안내한다. 현재 코드의 추가값과 일치한다. 크리확률을 `p`, 추가 크리데미지를 `c`, 스킬%를 `s`라 하면 비크리와 크리의 가중 평균은 `X × s/100 × (1 + p × c/s)`이므로 현재 크리 기대 배율의 구조를 설명할 수 있다. 이는 같은 기본 피해 `X`에서의 크리 여부 평균이며, 최소~최대 피해 전체의 평균이나 실측 DPS는 아니다.

[2026-07-10 공식 공지](https://mapleplanet.co.kr/news/updates/645)는 원작 크리티컬 스로우의 200% 표기가 플래닛의 추가 크리데미지 100%와 같다고 설명한다. 표기 차이를 이유로 현재 나이트로드의 추가값을 임의로 200%로 바꾸면 안 된다.

## 확인한 보완 대상

### 신궁의 샤프아이즈 패시브

[2026-08-28 공식 공지](https://mapleplanet.co.kr/news/updates/700)는 보우마스터·신궁의 샤프아이즈에 마스터 기준 크리확률 +10%, 크리데미지 +10% 패시브를 추가했다.

현재 `job-rules.ts`는 신궁의 기본 크확 40%·추가 크리데미지 100%를 사용하며, `calculate.ts`에는 해당 패시브의 별도 합산 또는 습득 수준 입력이 없다. 추가 크확 수동 입력으로 확률 일부를 보완할 수는 있지만, 추가 크리데미지의 별도 수동 입력은 없다. 따라서 마스터한 신궁의 환산공에는 공지된 보너스 누락이 있다. 반영 범위·스킬 수준·실제 동작 검증을 후속 과제로 남긴다. 캡틴·나이트로드에게 같은 패시브를 더하는 근거는 없다.

합성 조건에서 다른 추가 크확 없이 샤프아이즈 30·스킬 270%를 사용하면 현재 크확/추가 크리데미지는 55%/240%다. 공지의 마스터 패시브를 단순 가산하면 65%/250%이며 크리 배율은 약 1.488889 → 1.601852, 최종 버림 전 비율 차이는 약 +7.59%다. **공지에 따른 가정 계산이며 실전 피해 또는 DPS 측정값이 아니다.** 최대 스탯공 자체는 이 크리 보정으로 바뀌지 않는다.

### 합산 크리확률 상한

현재 입력의 추가 크확은 0~100으로 검증하지만, 직업 기본·샤프아이즈를 더한 최종 합계에는 상한이 없다. 정상 입력 경로에서 캡틴 추가 크확 100%·샤프아이즈 30을 넣으면 오류 없이 115%를 사용한다. 스킬 380%·추가 크리데미지 140%일 때 현재 크리 배율은 약 1.423684이며, 100% 제한을 적용한 산술값은 약 1.368421이다.

[2026-06-23 공식 공지](https://mapleplanet.co.kr/news/updates/623)의 크리확률 툴팁은 최대 100%를 명시한다. D-025에서 이미 기록한 계산 경계 문제를 재현했고 공식 근거를 보강했다. 이번 비교 요청만으로 계산 코드를 수정하지 않았다.

### 중간 버림과 실제 피해 범위

현재 코드가 최대 스탯공을 먼저 버린 뒤 환산 배율을 곱하는 단계는 실제 피해 계산의 마지막 버림과 구분해야 한다. 합성 DEX 1,001·STR 4·공격력 101·총데미지 50%·방어/크리 보정 없음에서 절사 전 최대값 3,643.676, 현재 최대 스탯공 3,643, 현재 환산공 5,464다. 최대값을 먼저 버리지 않는 산술식은 5,465를 반환한다. 차이는 재현되지만 어느 단계가 플래닛의 실제 타격 피해와 일치하는지는 이 비교만으로 확정할 수 없다. D-026에서 확인한 능력창 일치는 유지하며 별도 경계 실측이 필요하다.

제공 문서의 과거 피해 상한·고정 방어력·레벨 차감·특수 스킬 규칙을 현재 앱에 일괄 도입하지 않는다. 최소값·숙련도·타수·공격 주기·특수 스킬·상한을 다루지 않는 현재 환산공을 실제 평균 피해나 DPS로 표현하지 않는다.

- 합성 캡틴 DEX 1,000·STR 4·공격력 200의 최대값은 양쪽 기본식에서 7,208로 일치했다. 합성 나이트로드 LUK 1,000·DEX 25·STR 4·공격력 200의 일반 최대 스탯공은 7,258이며, 제공 문서의 트리플스로우 기본 최대는 10,000이다. 서로 다른 지표임을 구분한다.
- 계산 코드·OCR·사용자 저장값 변경 없음. 신규 인게임 측정·배포 없음. 개인 상세 자료를 이 문서에 복제하지 않았다.
