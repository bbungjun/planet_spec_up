## 미검증 및 미지원

실제 아란 캐릭터 자료는 아직 없다. 사용자는 공식자료 기반 구현부터 진행하도록 답했다. 폴암 계수·공% 대상·전직AP·타격별 버림/소비순서는 실측 미검증이다. 스킬1~19레벨·숙련도·속성·개별스킬 피해/분산·템페스트·연계DPS는 미지원이다. 공식 조사 결과를 현재 스탯공 일치나 사용자 POC 합격으로 표현하지 않는다. Production 반영은 승인하지 않았고 수행하지 않는다.

## 개발 데모

이 worktree에서 npm run dev -- --port 3001 후 http://localhost:3001/development 의 직업에서 아란을 선택한다. 합성 예: Lv160·순수STR800/DEX4·무기공100·메용20·기본길드5/10/30/5·콤보크리20 체크·콤보100이면 현재 참고 모델의 스탯공4624/환산공11652다. 이 값은 실제 게임 측정값이 아니다. 후보사진과 가격은 임시이며 새로고침 후 사라진다.
