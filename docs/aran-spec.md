# 아란 장비 비교 명세

상태: 2026-09-29 구현 계약. 요청 D-ARAN-001. 게임 실측 완료를 뜻하지 않는다. D-ARAN-020으로 /aran 참고 베타가 공개됐으며 후속 변경 배포는 별도 승인 대상이다.

## 범위와 진입

아란의 STR 주스탯·DEX 부스탯, 폴암 분류, 장비·순수 스탯·무기 3개 프리셋 등록/저장/복원, 임시 구매 후보·가격 비교, 옵션 효율·추가 스탯 시뮬레이터를 연결한다. 기본 `/`는 캡틴 전용을 유지한다. `/development`는 NODE_ENV=development에서만 접근하며 Production에는 404를 반환한다. 개발 세팅은 별도 저장 키를 사용해 기존 캡틴/일반 세팅을 덮어쓰지 않는다. 공개 /aran은 아란 고정·전용 저장 키를 사용한다.

## 계산 계약

- 순수 STR/DEX는 고정한다. 장비·후보·콤보 설정 변경으로 재배분하지 않는다.
- 장비 공%는 장비 공에만 적용한다. 아란에는 발사체를 합산하지 않는다.
- 공식 2026-07-17 콤보 크리티컬20 체크와 현재 콤보 입력으로 기본 크확10%·크리 표기100%, 콤보10당 +6%p·+10%p(최대10중첩)을 자동 계산한다. 미습득은 체크 해제로0이며 중간 스킬 레벨은 지원하지 않는다. 폴암 계수5는 공식 수치 미확인 참고 기본값이고 직접 수정할 수 있다. 하이 마스터리 체크는 기본 해제이며 체크 시 물리공격력 +10을 한 번만 비장비공으로 더한다. 숙련도90%는 최대 스탯공에 곱하지 않는다. 기타·콤보 추가공은 하이 마스터리를 제외해 직접 입력하며 기본0이다. 공% 제외 후가산은 기존 참고 가정을 유지한다.
- 계수/추가 공격력/콤보의 빈칸은 0으로 확정하지 않고 계산·확정 비교·효율·시뮬레이션을 보류한다. 명시적인 0은 미습득/효과 없음 모델이다.
- D-ARAN-023 사용자 정의에 따라 아란의 크리데미지 D%는 일반 피해 대비 총비율이며 크리 한 타격은 일반 타격의 D/100배다. 기대 보정은 (1-p/100)+(p/100)*(D/100)이며 대표 타격 배율을 사용하지 않는다. 구형 skillPercent 문자열은 저장 호환으로 보존하되 아란 입력/검증/계산에 쓰지 않는다. 출처별 크리 수치 합산은 기존 참고 모델이며 스킬 전체 DPS로 표현하지 않는다.
- 합산 크확 100% 초과 차단, 사냥 보공 제외, 장비 착용 가능성, 무기 미등록, 요구치/OCR 불확실성, 후보 원본 불변 조건을 유지한다.
- 기존 공통 AP 범위는 아란의 전직 AP 차이를 실측하지 않은 참고 가정이다. 실제 순수 STR/DEX를 고정하며 저레벨 지원을 게임 검증 완료로 표시하지 않는다.
- 조사에서 확정 가능한 수치는 출처와 함께 후속 보완할 수 있다. 콤보 어빌리티 공격력 곡선·숙련도·연계 타수·분산·템페스트·스킬별 피해·DPS는 지원 범위 밖이다.

## 확인 기준

합성 고정 입력의 수학적 검산, 기존 직업 회귀, 폴암 OCR 파서/STR·DEX/REQ DEX 매핑, 착용/크확 경계, 저장 왕복, 임시 후보 원본 보존, 효율/시뮬레이터, 캡틴 기본 화면 및 개발 화면 PC/모바일을 확인한다. 실제 아란 스크린샷 OCR 정확도·게임 스탯공 일치·독립 플레이어 POC는 별도 미검증으로 기록한다.

## 하이 마스터리 저장 호환 — D-ARAN-022

optional aranHighMastery 누락은 해제로 계산하고 기존 수동 추가공을 보존한다. 구형 저장값에 양수 추가공이 있는 상태에서 처음 체크하면, 포함된 +10을 분리하거나 기존 수치를 유지하고 별도 +10을 더할지 사용자가 선택하기 전까지 값을 바꾸지 않는다. +10 분리는 기존값이10 이상일 때만 제공한다. 취소는 입력을 보존한다. 새 세팅/명시적 체크값은 이 선택을 반복하지 않는다. 모든 프리셋·후보·효율·시뮬레이터는 공통 스냅샷의 동일 +10을 사용한다. 이번 구현은 사용자 직접 QA 지침에 따라 실행 검증/테스트 없이 개발 브랜치에만 반영하며 운영은 아직 이전 버전이다.

## 크리 총비율 의미 정정 — D-ARAN-023

사용자가 일반100%·크리235%이면 크리 피해가 일반의2.35배라고 확정해 아란만 기존 가산 크리 모델을 교체했다. 크리/외부 버프의 출처 합산값을 총비율로 해석하며 효과 합계0은 일반 피해 기준100으로 한 번 해석해 표시한다. 이 정의 확정이 콤보/샤프 출처별 숫자 합산의 실제 게임 정확도를 검증한 것은 아니다. 기존 계산/연구 표는 과거 참고 모델 기록으로 보존한다. 다른 직업 수식·최대 스탯공·하이 마스터리 처리는 유지한다. 사용자 직접 QA 요청에 따라 새 수식 실행 검증/테스트와 운영 배포는 하지 않았다.

## 장비 크리티컬 확률 — D-ARAN-024

장비 criticalRate는 퍼센트포인트 문자열이며 optional/빈칸을 보존한다. OCR의 크리티컬확률·크리확률은 % 표기가 있는 수치만 같은 정식 항목으로 읽고 기존 원문·숫자충돌·다중 판독 일치·검토 차단을 유지한다. 개별/일괄 OCR 검토, 카드/전체 옵션, 후보 사진/수동/상세/기존 반지 비교, 저장 프리셋이 같은 필드를 사용한다.

공통 계산의 크확은 기본/콤보 + 실제 장비(선택 무기1개 포함) + 장비 외 기타 + 샤프 버프다. 가상 불릿/축복/공버프 슬롯은 장비 크확 합산에서 제외한다. 장비 크확은 환산공에 영향을 주며 최대 스탯공은 바꾸지 않는다. 후보 누락값은 기존 장비 크확을 상속하지 않고 새 후보의 빈 입력으로 유지한다. 시뮬레이터/효율/후보의100% 상한 검사도 이 합계를 쓴다. 기존 수동 기타 크확을 장비값으로 추정해 자동 이동/차감하지 않는다. 개발 구현만 완료했고 이번 OCR 실행/브라우저/테스트 QA와 운영 배포는 하지 않았다.
