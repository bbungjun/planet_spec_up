# 아란 장비 비교 명세

상태: 2026-09-29 구현 계약. 요청 D-ARAN-001. 게임 실측 완료 또는 공개 직업 확대를 뜻하지 않는다.

## 범위와 진입

아란의 STR 주스탯·DEX 부스탯, 폴암 분류, 장비·순수 스탯·무기 3개 프리셋 등록/저장/복원, 임시 구매 후보·가격 비교, 옵션 효율·추가 스탯 시뮬레이터를 연결한다. 기본 `/`는 캡틴 전용을 유지한다. `/development`는 NODE_ENV=development에서만 접근하며 Production에는 404를 반환한다. 개발 세팅은 별도 저장 키를 사용해 기존 캡틴/일반 세팅을 덮어쓰지 않는다.

## 계산 계약

- 순수 STR/DEX는 고정한다. 장비·후보·콤보 설정 변경으로 재배분하지 않는다.
- 장비 공%는 장비 공에만 적용한다. 아란에는 발사체를 합산하지 않는다.
- 공식 2026-07-17 콤보 크리티컬20 체크와 현재 콤보 입력으로 기본 크확10%·크리 증가분100%, 콤보10당 +6%p·+10%p(최대10중첩)을 자동 계산한다. 미습득은 체크 해제로0이며 중간 스킬 레벨은 지원하지 않는다. 폴암 계수5는 공식 수치 미확인 참고 기본값이고 직접 수정할 수 있다. 콤보/마스터리 공격력은 현재 상태의 추가 공격력으로 직접 입력하며 기본0(효과 없음)이다. 비장비 공으로 더하는 가정을 표시한다.
- 계수/추가 공격력/콤보의 빈칸은 0으로 확정하지 않고 계산·확정 비교·효율·시뮬레이션을 보류한다. 명시적인 0은 미습득/효과 없음 모델이다.
- 대표 타격 배율은 기본100%의 정규화 비교 모델이며 사용자가 입력을 바꿀 수 있다. 공식 3/24 크리 가산 구조와 공통 크리 기대 보정식을 사용한 참고 환산공이며 아란 스킬 전체 또는 DPS로 표현하지 않는다.
- 합산 크확 100% 초과 차단, 사냥 보공 제외, 장비 착용 가능성, 무기 미등록, 요구치/OCR 불확실성, 후보 원본 불변 조건을 유지한다.
- 기존 공통 AP 범위는 아란의 전직 AP 차이를 실측하지 않은 참고 가정이다. 실제 순수 STR/DEX를 고정하며 저레벨 지원을 게임 검증 완료로 표시하지 않는다.
- 조사에서 확정 가능한 수치는 출처와 함께 후속 보완할 수 있다. 콤보 어빌리티 공격력 곡선·숙련도·연계 타수·분산·템페스트·스킬별 피해·DPS는 지원 범위 밖이다.

## 확인 기준

합성 고정 입력의 수학적 검산, 기존 직업 회귀, 폴암 OCR 파서/STR·DEX/REQ DEX 매핑, 착용/크확 경계, 저장 왕복, 임시 후보 원본 보존, 효율/시뮬레이터, 캡틴 기본 화면 및 개발 화면 PC/모바일을 확인한다. 실제 아란 스크린샷 OCR 정확도·게임 스탯공 일치·독립 플레이어 POC는 별도 미검증으로 기록한다.
