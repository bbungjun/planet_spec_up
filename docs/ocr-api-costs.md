# 외부 OCR API 비용 참고

확인일: 2026-09-26. 비용 조사 자료이며 공급자 선정·결제·외부 이미지 전송의 승인이 아니다. 현재 제품 정책은 브라우저 내부 OCR이다.

## Google Cloud Vision 예시

공식 [Cloud Vision 가격표](https://cloud.google.com/vision/pricing?hl=ko) 기준 Text Detection 또는 Document Text Detection 한 기능을 이미지마다 한 번 실행한다고 가정한다. 월 첫 1,000단위는 무료, 이후 월 5,000,000단위까지 1,000단위당 $1.50이다. 월 중 마지막 1,000단위 미만 사용량도 비례 계산한다.

| 월 OCR 호출량 | 예상 API 요금(USD) | 원화 예시 |
| --- | ---: | ---: |
| 1,000회 | $0 | 0원 |
| 5,000회 | $6.00 | 9,000원 |
| 10,000회 | $13.50 | 20,250원 |
| 100,000회 | $148.50 | 222,750원 |

원화는 이해를 돕기 위해 **$1 = 1,500원으로 가정**한 값이지 현재 환율이나 원화 청구 견적이 아니다. 실제 원화 결제는 공급자의 해당 통화 SKU·결제 조건에 따르며 세금, 서버·스토리지·전송 등의 부가 비용은 위 예시에서 제외했다.

위 사용 구간의 산식: `max(0, 월 OCR 청구 단위 - 1000) × $0.0015`.

## 이 앱에 적용할 때의 주의점

- 모든 방문자가 하나의 운영자 API 계정을 사용하면 그 사용량을 합산한다. 무료 1,000단위를 방문자마다 제공되는 혜택으로 계산하지 않는다.
- 이미지 수가 곧 호출 수인 것은 아니다. 원본/확대본 재호출, 재시도, 두 종류 기능 실행은 청구 단위를 늘릴 수 있다. 여러 이미지를 한 HTTP 요청에 묶는 것만으로 각 이미지의 인식 요금이 없어지지 않는다.
- 예시로 월 10,000장을 처리하되 10%인 1,000장만 외부 OCR에 각각 1회 보낸다면 위 무료 구간 안이다. 이는 실패율 10%라는 가정일 뿐 현재 앱의 측정 실패율이 아니다. 무료 할당량의 다른 사용도 확인해야 한다.
- 내부 OCR의 외부 인식 API 요금은 0이다. 그렇다고 사이트 호스팅·트래픽·모델 파일 배포와 이용자 기기 연산이 모두 무료라는 뜻은 아니다.
- API 가격만으로 게임 툴팁 정확도를 보장하지 않는다. 작은 글자·반투명 배경·잠재 옵션 반복 줄이 있는 대표 샘플에서 먼저 검증해야 한다.
- 일반 OCR 서비스 비용과 LLM 이미지 분석·위키 챗봇 비용은 별개다. 이 표에는 LLM 사용료가 포함되지 않는다.

## 도입을 별도로 승인받을 경우

자동 전환하지 말고 전송 대상과 비용을 안내한 명시적 사용 동작으로 제한한다. 비밀 키를 브라우저에 노출하지 않고 서버 중계, 요청 제한, 중복 억제, 일/월 호출 상한과 중단 장치를 준비한다. 운영자 예산은 사용자가 결정하며, 이 문서가 예산을 승인하지 않는다.

단가는 도입 직전에 공식 가격표에서 재확인한다.
