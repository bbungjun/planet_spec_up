MVP 구조와 데이터 흐름

화면과 공식을 분리해 이번에는 수동 입력을 받고, 2단계에서는 입력 출처만 OCR로 추가합니다.

현재 MVP

PC 계산 화면

직업 선택, 장비 슬롯 편집, 기타 세팅, 저장 슬롯 1개를 담당합니다. 입력이 바뀌면 즉시 표준 데이터로 변환합니다.

→
공용 핵심

독립 계산 엔진

React 화면을 전혀 모르는 순수 계산 모듈입니다. 신궁·캡틴·나이트로드 규칙과 행성.com 대응 공식을 실행합니다.

→
실시간 출력

결과 패널

최종 스탯, 스탯 공격력, 환산 공격력과 계산 근거를 표시합니다. 입력 오류가 있으면 결과 대신 수정할 위치를 안내합니다.

계산 엔진 내부
1. 입력 정규화빈칸은 0으로 처리하고 수치 범위를 검증
2. 장비 합산부위별 고정 스탯·% 스탯·공격력을 합산
3. 직업 규칙주/부스탯, 무기 상수, 레벨·버프를 적용
4. 결과 계산스탯공과 방어율·보공 등을 포함한 환산공 산출

이번 MVP에 포함

  • 신궁 · 캡틴 · 나이트로드
  • 수동 장비 입력과 실시간 계산
  • 브라우저 개인 저장 슬롯 1개
  • 행성.com 기준 결과 대조 테스트

2단계에서 연결

  • 아이템 스크린샷 업로드
  • OCR 옵션 인식과 사용자 검수
  • 검수된 값을 같은 계산 엔진에 전달
  • 위키·챗봇은 별도 서비스로 연결
핵심 원칙: OCR은 계산을 하지 않고 입력값만 만들어냅니다. 계산의 정답은 언제나 하나의 공용 엔진이 담당합니다.
