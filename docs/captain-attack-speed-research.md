# 캡틴 윈드 부스터·공격속도·DPS 조사

확인일: 2026-09-29 KST. 사용자 요청은 조사이며 계산식 변경·기능 도입·운영 배포 승인이 아니다. 관련 기록: D-164.

## 조사 결과

윈드 부스터의 효과는 공격력 숫자를 더하는 방식보다 실제 공격 주기의 변화로 모델링해야 한다. 캡틴의 모든 피해에 같은 상승률을 곱하는 근거는 확보하지 못했다. 배틀쉽 캐논의 반복 주기, 래피드 파이어의 키다운 탄 간격, 사냥 스킬의 모션/재사용 간격, 소환수 주기를 각각 확인해야 한다.

현재 앱의 최대 스탯공·환산공과 사냥 스킬 최대 참고 피해에는 공격속도·윈드 부스터·초당 공격 횟수가 없다. 따라서 현재 결과는 윈드 부스터의 시간당 공격 효과를 표현하지 않는다. 기존 환산공에 공통 속도 배율을 넣는 대신 별도의 스킬별 시간 지표를 검토하는 것이 에이전트 제안이다.

## DPS에 반영하는 산술

한 번 시전의 기대 피해를 D, 실제 반복 간격을 t ms라 하면, 중단 없이 같은 스킬을 반복하는 모델은 다음과 같다.

```text
시전 횟수/초 = 1000 / t
DPS = D × 1000 / t
전후 DPS 비율 = (변경 후 D / 변경 전 D) × (변경 전 t / 변경 후 t)
```

D가 이미 시전 전체 피해면 타수를 다시 곱하지 않는다. 한 줄 피해라면 실제 시전당 유효 타수를 반영해야 한다. D에는 최대값이 아니라 숙련도·난수·크리·방어·속성·상한을 고려한 기대 피해가 필요하다. 현재 환산공은 최대 스탯공에서 시작하고 최종 스킬 배율·타수·숙련도 평균이 없으므로 이를 그대로 절대 DPS로 바꿀 수 없다.

동일 피해가 유지되고 캐논의 실제 반복 간격이630→600ms라면 속도 효과는630/600−1=5%다.690→600ms라면15%다. 이것은 원작 시간값을 이용한 조건부 산술이며 플래닛 실측 상승률이 아니다.

장비 교체의 한 시전 피해가10% 상승하고 실제 주기가630→600ms로 바뀐다는 별도 가정에서는1.10×1.05−1=15.5%다. 피해 상승률과 속도 상승률을 단순 합산하지 않는다. 공속 상한에 이미 도달했거나 반복 주기가 그대로라면 속도에 따른 직접 상승률은0이다.

쿨타임 스킬은 실제 재시전 주기를 사용한다. 재사용시간이 시전 시작부터 세어지고 별도 제한이 없다는 가정에서만 모션 시간·재사용시간 중 긴 값을 반복 간격으로 볼 수 있다. 쿨타임이 모션 종료 후 시작하면 모형이 달라진다. 플래닛의 시작 시점은 미확정이다. 에어 스트라이크의 모션을 줄여 얻은 빈 시간에 다른 공격을 넣는 효과는 전체 스킬 순서로 따로 계산한다.

여러 스킬과 소환수가 섞인 피해는 각 기여를 합산한다. 영향받는 공격의 기존 피해 비중이70%이고 그 공격의 DPS만5% 증가하며 나머지 행동/가동률이 유지되는 가정에서는 전체 증가는3.5%다. 이동·스킬 전환·재소환·배틀쉽 중단 때문에 비중 자체가 바뀌면 이 단순식도 재검토한다.

## 플래닛에서 필요한 검증

1. 무기명·표기 공속·건 부스터 유무·윈드 부스터 종류/레벨·게임 패치·측정 환경을 기록한다. 일반 윈드 부스터와 쓸만한 계열이 있다면 존재와 중첩 규칙부터 따로 확인한다.
2. 같은 장비·같은 대상·같은 스킬 레벨에서 윈드 부스터만 바꾼다. 건 부스터는 양쪽 동일 상태로 유지한다. 미스·넉백·이동·처치·버프 만료·배틀쉽 파괴가 없는 구간부터 비교한다.
3. 캐논과 래피드는 우선 각각30~60초의 연속 구간을3회 이상 촬영한다. 시작/종료 시간을 분리하고 중간의 시전/발사 간격을 구한다. 영상 FPS와 프레임 누락, 투사체 도달시간·데미지 숫자 표시 지연을 기록한다. 측정 조건을 갖출 수 없으면 미확정으로 둔다.
4. 첫 시전 t1부터 마지막 tN까지 N회를 확인했다면 평균 간격은(tN−t1)/(N−1)이다. 여러 타격 줄을 여러 시전으로 세지 않는다. 프레임 간격을 비교해 중앙값·변동도 함께 남긴다.
5. 파이어 버너·쿨링은 동일 스킬 반복과 다른 행동 전환을 별도로 측정한다. 에어 스트라이크는 재사용 간격·행동 잠금·남는 시간에 넣은 공격을 분리한다.
6. 옥토퍼스는 한 소환수의 공격 주기, 개수·지속시간·타깃 확보·재소환을 따로 기록한다.6월18일 공지의 중복 소환 수정이 최대 소환수 수나 강화 후 공격 주기를 확정하는 것은 아니다.

이 절차는 제안이며 게임 실측을 이미 완료했다는 뜻이 아니다. 캡틴의 실제 무기·버프별 단계가 확인되기 전에는 원작 상한과 단계 증감을 제품 기본값으로 확정하지 않는다.

## 앱 반영을 검토할 때의 범위

- 기존 스탯공·환산공·가격 효율은 유지한다. 공격력 버프 숫자에 윈드 부스터 값을 더하지 않는다.
- 별도 스킬별 공격 주기/상대 DPS 화면을 검토한다. 무기 공속·건 부스터·윈드 부스터·스킬별 실제 반복 간격과 근거 상태가 필요하다.
- 우선 캐논 지속 공격과 래피드 키다운을 분리하고, 소환수·재사용시간·이동을 이후 통합한다. 절대 DPS에 필요한 기대 피해가 확보되지 않으면 시간/빈도와 조건부 상대 변화만 표시한다.
- 원작 참고·플래닛 실측·미확정을 구분한다. 미확정 주기를0이나 공통 배율로 채우지 않는다. 일반 환산공을 전체 사냥/보스 DPS로 이름만 바꾸지 않는다.
- 타이밍 모델 도입과 운영 반영에는 후속 사용자 요청이 필요하다. 이번 조사는 기능·저장 스키마·공개 버전을 변경하지 않는다.
