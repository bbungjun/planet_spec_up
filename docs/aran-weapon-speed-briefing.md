# 아란 폴암 계수와 무기 속도 비교

확인일: 2026-09-29. 현 앱의 코드 점검 및 공개 근거 설명이며 새 계산 구현·정책 변경 요청으로 해석하지 않는다.

## 지금 쓰는 계수5의 의미

현재 모든 아란 폴암은 캐릭터 설정의 같은 계수를 사용한다. 기본값5는 [Ayumilove의 2009 Formula Compilation](https://ayumilovemaple.wordpress.com/2009/09/06/maplestory-formula-compilation/)에 있는 Polearm(Swinging)의 STR×5·DEX 최대식에서 선택한 **원작 비공식 참고값**이다. [플래닛 7/14 정정](https://mapleplanet.co.kr/news/notices/649)은 실제 모션과 무관한 스윙 판정 의도를 설명하지만 숫자 계수5를 명시한 근거는 아니다. [플래닛 4/2 패치](https://mapleplanet.co.kr/news/updates/483)의 폴암 스탯창 찌르기 계수 표시 오류 수정도 숫자5의 확정 근거는 아니다. 현재 플래닛의 실제 폴암 스탯창과 일치한다고 검증하지 않았다.

코드 위치: `job-rules.ts:28`, `defaults.ts:24`, `calculate.ts:164`. 계수는 직접 바꿀 수 있지만 **무기마다 다른 계수를 저장하거나 후보에 따라 바꾸는 기능은 없다**. 공격속도가 빠르다는 이유로 계수를 늘리거나 줄이지 않는다.

현재 산술 단계는 다음과 같다. 이것은 앱의 참고 계산 순서이며 인게임 타격별 버림을 실측한 공식이 아니다.

1. STR/DEX 각각 `floor((순수+장비/달성보너스)×(1+스탯%/100)) + floor(순수×메용증가율)`.
2. 공격력 `floor(장비공×(1+공%/100)) + 비장비공`. 아란 추가공은 비장비 후가산 가정이고 발사체는 제외한다.
3. 최대 스탯공 `floor((최종STR×계수+최종DEX)×총공/100)`.
4. 참고 환산공 `floor(최대스탯공×데미지배율×방어율배율×(1+크확/100×크리증가분/대표타격배율))`.

`formulas.ts:11/19/38/45`와 `calculate.ts:140~172`가 위 단계를 구현한다. [공식 3/24 크리 가산 설명](https://mapleplanet.co.kr/news/updates/465)에 기반한 기대 보정을 쓰지만 대표타격 기본100%는 정규화 비교 가정이며 실제 아란 연계 배율이 아니다. [7/17 공식](https://mapleplanet.co.kr/news/updates/653)의 콤보 크리20만 현재 콤보에서 자동 반영한다.

## 현재 후보 비교가 포함하는 것

| 항목 | 현재 상태 |
| --- | --- |
| 실제 입력한 두 무기의 최종 스탯·공격력·공%·총뎀·보공·방무 | 동일 전투 조건으로 장비 하나를 바꿔 스탯공/참고 환산공 비교 |
| 순수STR/DEX·버프·대상방어율·현재콤보·대표배율 | 비교 전후 고정 |
| 크리20 미습득/마스터·고정 콤보 효과 | 지원 |
| 개별 무기 이름에 따른 공속 규칙·공속단계/공속상한/폴암 부스터 | 계산 필드 및 자동 효과 없음 |
| 무기별 모션·스킬별 프레임·연계/후딜·초당 공격횟수 | 미구현 |
| 최소/평균 타격·콤보 획득/소비의 시간 변화·속성/상한/분산 | 아란 DPS 모델 미구현 |
| 퍼플 서프보드와 특정 리버스 폴암의 실제 비교 | 미수행. 기존 검증은 합성 폴암의 공100→110과 옵션 교체뿐 |

`candidates.ts:44~48`은 같은 캐릭터/전투 설정에서 후보 장비 레코드만 교체한다. `types.ts`에는 공속/부스터/프레임/DPS 입력이 없다. 따라서 공속이 서로 다른 무기의 현재 환산공 상승률은 **실제 DPS 상승률 또는 어느 무기가 더 강하다는 확정 판정이 아니다**.

## 두 무기의 DPS를 비교하려면

이번 공개 자료 확인에서 MapleStory.IO의 **GMS/83 버전 데이터**는 다음 값을 반환했다. 연구자가 버전을 지정한 API의 실제 JSON을 확인했으며 이 표는 플래닛 툴팁·강화 후 장비·현행 게임의 확정값이 아니다. 사용자가 말한 리버스 폴암을 Reverse Diesra로 가정해 조회한 것이며 실제 아이템명이 다르면 별도 확인해야 한다.

| GMS/83 데이터 | 공속 코드 | 기본 공격력 | 출처 |
| --- | --- | --- | --- |
| Purple Surfboard, ID1442057 | 5 | 99 | [버전 지정 API](https://maplestory.io/api/GMS/83/item/1442057) |
| Reverse Diesra, ID1442067 | 8 | 112 | [버전 지정 API](https://maplestory.io/api/GMS/83/item/1442067) |

[Hidden Street 검색 표시](https://bc.hidden-street.net/eq/polearm/reverse-diesra)에는 공속9가 나오지만 직접 본문 요청은403으로 확인하지 못했다. 이 표시는 추가 확인할 단서이며 검증된 게임 수치로 쓰지 않는다. 버전을 생략하고 리버스 공속8을 확정하지 않는다. [구버전 아란 스킬/FAQ](https://ayumilovemaple.wordpress.com/2009/08/16/maplestory-aran-skills-skill-build/)의 퍼플 공속5·부스터+3·상한2도 플래닛 적용을 검증한 근거는 아니다. 공속 코드 차이는 그 자체로 공격 횟수 비율이 아니며, 다른 스킬의 지연시간 표를 아란 스윙/오버스윙 연계에 대입하지 않는다.

우선 플래닛 현재 툴팁의 정확한 무기명·공격속도·최종 옵션, 부스터 등 공속 버프, 사용 스킬/연계·전투 대상을 같은 기준으로 확인해야 한다. 공속 등급의 숫자만으로 몇% 빠르다고 환산하지 않는다. 적용 후 공속이 같거나 상한에 함께 도달하는지도 실제 주기와 함께 확인한다.

같은 콤보 상태와 같은 연계를 반복하는 조건에서, 독립적으로 구한 평균 사이클 피해를 D·사이클 시간을 T라고 하면 제안 비교식은 다음과 같다.

`후보 DPS/기존 DPS = (후보 평균 사이클 피해/기존 평균 사이클 피해) × (기존 사이클 시간/후보 사이클 시간)`

예를 들어 **가상의** 후보가 사이클 피해는5% 높지만 시간은10% 더 길면 비율은1.05/1.10≈0.9545, DPS는 약4.55% 낮다. 이는 두 실제 무기의 수치가 아니다. 현재 앱의 최대 스탯공/참고 환산공을 측정한 평균 사이클 피해라고 대신 넣으면 안 된다.

빠른 무기가 콤보를 더 빨리 쌓거나 콤보 소비 후 복구가 다르면 고정 콤보 식만으로 부족하다. 각 시점의 콤보·패시브·크리·스킬 사용/소비를 추적하고, 동일 시간창의 총 기대 피해를 합산하는 모델 또는 통제된 전투 측정이 필요하다. 이 문서의 비교 방법은 후속 제안이며 이미 구현/실측한 결과가 아니다.

무기 속도에 관한 공개 자료 확인 결과는 [조사 문서](aran-research-findings.md)에 이어 기록한다. 현재 플래닛 수치 미확인 항목은 원작/다른 서버 값을 자동 대입하지 않는다.
